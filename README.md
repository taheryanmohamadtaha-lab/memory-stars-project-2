# ستاره‌های حافظه (Memory Stars)

اپلیکیشن اندرویدی فلش‌کارت لایتنر برای کودکان؛ فارسی، راست‌چین و آفلاین.
شناسه بسته: `com.memorystars.leitner` — حداقل اندروید ۸ (API 26).

## قابلیت‌ها
- ساخت دسته و کارت (متن، دوربین، گالری، ترکیب متن و عکس)، ویرایش، کپی، جست‌وجو و حذف با تأیید
- لایتنر ۵ جعبه‌ای واقعی: «بلدم» یک جعبه جلو می‌برد، «هنوز یاد نگرفتم» به جعبه ۱ برمی‌گرداند و کارت یک بار چند کارت بعد دوباره می‌آید
- فاصله‌های مرور قابل تغییر (پیش‌فرض ۱، ۲، ۴، ۷، ۱۴ روز)
- XP، ۶ سطح، ۹ نشان، هدف روزانه و زنجیره روزها (بدون تنبیه)
- ۹ تم، حالت روشن/تاریک/سیستم، کاهش انیمیشن، فونت بزرگ
- گزارش پیشرفت، بخش والدین (قفل ساده، نه امنیت بانکی)، پشتیبان‌گیری ZIP و بازیابی
- بدون اینترنت، تبلیغ یا ردیابی

## مرور و تمرین آزاد
از صفحه اصلی یا صفحه هر دسته: حالت‌های کلاسیک (سبز/قرمز)، چهارگزینه‌ای، تایپ پاسخ و جفت‌کردن؛ با گزینه معکوس، فیلتر (ضعیف، یادگرفته، اشتباه‌شده)، ترتیب (ترتیبی، اتفاقی، سخت‌ترین‌ها اول) و بدون محدودیت. تمرین روی جعبه‌های لایتنر و امتیاز اثری ندارد.

## ساختار
- `data/` پایگاه داده Room، DataStore، تصاویر، پشتیبان
- `domain/` منطق لایتنر و امتیازها (خالص و تست‌شده)
- `ui/` صفحه‌ها (Compose)، `AppViewModel`، تم‌ها
- `.github/workflows/android-ci.yml` ساخت Debug APK، `release.yml` ساخت Release امضاشده (دستی)

## دریافت APK از GitHub
1. در GitHub یک مخزن جدید بساز.
2. همه فایل‌های این پوشه را در ریشه مخزن آپلود یا push کن (پوشه پنهان `.github` را فراموش نکن).
3. به تب **Actions** برو؛ Workflow «Android CI» خودکار اجرا می‌شود (یا «Run workflow»).
4. اجرای موفق را باز کن و در پایین صفحه، بخش **Artifacts**، فایل `memory-stars-debug-apk` را دانلود کن.
5. ZIP را استخراج کن و `app-debug.apk` را روی گوشی نصب کن (در صورت نیاز «نصب از این منبع» را فعال کن).
6. اگر ساخت شکست خورد، روی مرحله قرمز کلیک کن و لاگ را ببین.

APK فقط در Artifacts قرار می‌گیرد و خودکار در صفحه اصلی مخزن منتشر نمی‌شود.
**Debug APK** برای آزمایش و نصب شخصی است و به رمز نیاز ندارد. **Release امضاشده** برای انتشار است و فقط با Secrets (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) ساخته می‌شود؛ هیچ کلیدی در مخزن نگذار.

## نکته Gradle Wrapper
فایل `gradle-wrapper.jar` در این بسته نیست؛ Workflow با `gradle/actions/setup-gradle` نسخه 8.9 را نصب می‌کند. برای ساخت محلی در Android Studio پروژه را باز کن یا `gradle wrapper` را یک بار اجرا کن.
